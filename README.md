# cat-charity-2
## Описание проекта.

QRKot - это проект для фонда QRKot. В этом приложении можно открывать «целевые проекты» — сборы конкретных сумм под конкретную задачу, а пользователи могут отправлять пожертвования для сбора требуемых сумм. Приложение также имеет возможность по автоматической публикации отчета о выполненных проектах.


## Технологический стек проекта.
- Python 3.12  
- FastAPI 
- FastAPI Users 
- Alembic
- SQLAlchemy 
- SQLite 


## Начало работы с проектом.


Необходимо клонировать репозиторий и перейти в него в командной строке:

```
git clone git@github.com:GalinaLody/QRkot-spreadsheets.git

cd QRkot-spreadsheets
```
Cоздать переменные окружения .env на основании .env.example:

```
cp .env.example .env
```
## Как запустить проект.


Создать и активировать виртуальное окружение:

```

python -m venv venv

source venv/Scripts/activate
```
Обновить pip, установить зависимости:

```
pip install --upgrade pip

pip install -r requirements.txt

```

Запустить веб-сервер разработки:

```
uvicorn app.main:all --reload
```

После запуска открыть [сервер](http://127.0.0.1:8000) в браузере.

Запросы к API могут быть отправлены на следующие эндпоинты:
* http://127.0.0.1:8000/charity_project/
* http://127.0.0.1:8000/charity_project/{project_id}
* http://127.0.0.1:8000/donation/
* http://127.0.0.1:8000/donation/my/
* http://127.0.0.1:8000/auth/jwt/login/
* http://127.0.0.1:8000/auth/jwt/logout/
* http://127.0.0.1:8000/auth/register
* http://127.0.0.1:8000/yandex/

Для просмотра полного списка целевых проектов(открытых и закрытых) регистрации не требуется. Для отправки пожертвования и просмотра
полного списка своих пожертвований требуется регистрация пользователя. Правом на создание проектов, изменение названия и описания существующего проекта, удаление проекта, в которые не было внесено средств, просмотр списка всех пожертвований обдалает только суперпользователь. Суперпользователь может запросить сформировать и опубликовать на Яндекс Диске отчет о закрытых проектах с данными о сроках получения полной суммы донатов.



Пример запроса:
```
{
  "name": "string",
  "description": "stringstri",
  "full_amount": 1
}
```


Пример запроса:
```
{
  "full_amount": 1,
  "comment": "string"
}
```
